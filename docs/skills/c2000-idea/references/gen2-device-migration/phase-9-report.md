# Phase 9 — Report

Write the final report to the log under `## Phase 9 — Report` and show it to the user:

1. **Projects:** source project and family, target project and family, C2000Ware version.
2. **Files:** each target file, with the number of register rows ported, mapped and dropped.
3. **Mapped:** each peripheral moved to another peripheral or pin, and why it performs the same function.
4. **Dropped:** CLA code and peripherals the target does not have, and what the application loses.
5. **Clocks and rescaling:** the target clocks, and every rescaled setting with its error.
6. **Pins:** the target pin plan, to use for the new board.
7. **Verification:** the Phase 8 result per class, and the reviewer's findings.
8. **To check on hardware:** analog behavior (ADC references, trims and acquisition windows), CAN bit
   timing on the bus, external memory timing, oscillator and clock settings, and every Defect fixed in
   Phase 8.
9. **Builds:** the configurations built and the configurations not built.
